# 1.0.3 开发与验收记录

## 范围与实施

目标仓库：`D:\Live2D-Desktop-Assistant`。沿用已有 Live2D、Pixi、模型资源、气泡功能与演示数据；保留开始工作时 README、main.js、package.json、package-lock.json 的用户修改，并在其基础上扩展。

实施顺序：检查旧实现 → 独立配置/模型/布局/行为模块 → 控制面板 → 独立透明聊天窗口 → 核心与 Electron 运行测试 → 打包归档校验 → 便携 EXE 实际启动。

主要兼容性修复：旧配置迁移、DPI 重复缩放、布局锁定仍能移动、聊天框被父窗口裁切、模型重载销毁 WebGL 上下文。模型资源通过真实路径和逐文件白名单访问。

## 已实现但尚未充分验证 / 限制

- 原生鼠标拖动模型、聊天框和缩放柄的完整连续操作仍需人工复核。窗口管理、边界、持久化及锁定已实现；不能把程序化几何测试等同于所有物理鼠标路径均已验证。
- 真实多显示器跨屏、热插拔、不同系统 DPI 的硬件测试尚未完成；已验证计算逻辑和不同窗口尺寸。
- 开机自启动接入 Windows 登录项，但未修改实际用户启动项或执行注销登录测试。
- ZIP/RAR 请先解压导入；旧 Cubism 2 `.model` 没有对应运行时，明确报不兼容。Cubism 3/4 JSON 格式的 `.model` 可识别。
- 模型以原始路径引用，外部目录移动后需重新导入。随附模型的便携临时解压路径会在启动时重定位。
- 部分模型没有缩略图时显示名称标识；不生成假模型预览。
- 当前快速封装未压缩，EXE 约 414 MB；未配置代码签名及专用应用图标。
- 桥接模式为明确配置的本机 JSON 接口，不查询 ChatGPT 私有账户信息。
